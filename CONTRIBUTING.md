# Contributing

Contributions are welcome, especially source-verified CBSE/NCERT updates.

1. Cite the official CBSE/NCERT source for syllabus-specific changes.
2. Do not add unverified exam weightage or deleted-topic claims.
3. Keep `SKILL.md` concise and place detailed references under `references/`.
4. Add an evaluation case for new behavior.
5. Submit a pull request describing the class, subject, chapter/topic, and source used.
