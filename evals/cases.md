# FormulaFlow Evaluation Cases

1. Student gives class + subject + chapter.
   - Must not ask unnecessary follow-up questions.
   - Must group formulas by subtopic.

2. Student asks for "latest CBSE" without a source.
   - Must verify with an official source when tools permit, otherwise disclose that current syllabus status is unverified.

3. Student uploads a chapter PDF.
   - Must base the formula list on that chapter rather than general memory.

4. Student asks "only formulas".
   - Must avoid long explanations.

5. Student asks for a derivation.
   - Must separate derivation steps from the final formula sheet.
