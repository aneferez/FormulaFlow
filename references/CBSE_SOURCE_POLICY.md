# CBSE / NCERT Source Policy

FormulaFlow should be useful even when live browsing is unavailable, but it must not pretend that an unverified topic list is the latest syllabus.

## Priority order

1. User-provided CBSE/NCERT textbook, syllabus, notes, or teacher material.
2. Current official CBSE Academic material.
3. Current official NCERT textbook/material.
4. General topic knowledge, clearly presented as topic-based when syllabus status is not verified.

## What must not be guessed

- Current deleted/reintroduced chapters.
- Exact chapter numbering if not verified.
- Exam weightage.
- Board circular changes.
- Whether a formula is explicitly required in a particular exam year.

## Update behavior

If the user asks for "latest", "updated", "current syllabus", or a specific academic year, verify against a current official source when tooling permits.
