# FormulaFlow Output Schema

## Compact formula mode

Use when the user asks for "formula list", "formula sheet", or "only formulas".

```text
Subtopic
1. Formula
   Symbols:
   Unit:
   Note:
```

## Teaching mode

Use when the user asks to explain.

```text
Concept
Formula
Meaning of symbols
When to use it
Worked example
Common mistake
```

## Revision mode

Use for exam revision.

- Group by chapter/subtopic.
- Put the highest-use formulas first.
- Add unit reminders.
- Add a final "Common Confusions" section only when useful.

## Formatting

- Prefer Unicode math only when it remains readable.
- Use LaTeX-style notation when the interface supports it.
- Do not bury formulas in prose.
- Keep examples short unless a full solution is requested.
